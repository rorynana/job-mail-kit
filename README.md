# 공고 메일 키트

AI 도구에게: 이 키트를 받았으면 먼저 AGENTS.md 를 읽고 그 1~6단계대로 진행한다.

사람인·잡코리아의 마케팅 공고를 내 점수표로 매겨, 매일 아침 9시에 내 Gmail 로 점수 높은 공고 10개를 보내는 키트입니다.

## 쓰는 법

AI 코딩 도구(Claude Code, Codex 등)를 연 터미널에 한 줄이면 됩니다.

    github.com/rorynana/job-mail-kit 키트 받아서, 설명서대로 매일 아침 9시에 내 Gmail로 공고가 오게 해 줘.

AI가 키트를 받고, 나를 인터뷰해 점수표를 만들고, 한 번 돌려 상위 공고를 보여 주고, 내 GitHub 비공개 저장소로 올립니다. 순서는 AGENTS.md(CLAUDE.md 와 같은 내용)에 있습니다.

내가 직접 하는 일은 두 가지입니다.
1. GitHub 로그인 승인 (브라우저에 코드 8자리)
2. Gmail 앱 비밀번호를 GitHub Secrets 에 넣기 (2단계 인증을 먼저 켜야 만들 수 있습니다)

## 들어 있는 것

- collect.js : 사람인·잡코리아 「마케팅」 검색 공고를 모아 jobs.csv 로. 제목에 마케팅·마케터·콘텐츠·홍보·SNS 가 든 공고만. 한 사이트가 막혀도 나머지로 저장. 요청 사이 1초
- score.js : criteria.json 점수표대로 공고마다 점수와 이유를 붙여 scored.csv 로. AI를 부르지 않고 규칙으로만 매깁니다
- mail.js : 기준선(기본 60점) 이상 중 점수 높은 10개를 Gmail 로. 없는 날은 「오늘은 없음」
- .github/workflows/daily.yml : GitHub Actions 로 매일 한국 시간 아침 9시(UTC 0시)에 위 셋을 돌립니다. 내 컴퓨터가 꺼져 있어도 돕니다
- criteria.예시.json : 점수표 예시. 서울 노원 거주, SNS 콘텐츠 마케팅 희망 가상 구직자

## 점수표 구조 (criteria.json)

- 기준선, 보낼 개수
- 0점 조건 : 이 단어가 보이면 그 공고는 0점
- 항목 : 배점 합 100. 단어가 보이면 그 단계 점수, 칸이 비면 배점 절반, 아무 단어도 안 맞으면 나머지 점수. 경력은 「최소 몇 년」으로 매깁니다
- 쓸 수 있는 칸 : 회사, 공고 제목, 지역, 경력, 근무 형태 (공고 목록에 연봉은 없습니다)

## 비용

GitHub 무료 계정 비공개 저장소는 Actions 를 한 달 2,000분 씁니다. 한 번 도는 데 1분 안팎이라 매일 돌려도 한 달 30분 정도입니다.
